INSTINCTIVE GROWTH WEBSITE

Files:
- index.html
- style.css
- script.js
- assets/monogram.png

Before launch:
1. Replace hello@instinctivegrowth.com in script.js with your actual email.
2. Upload this folder to GitHub.
3. Connect the GitHub repository to Cloudflare Pages.
4. Add your custom domain in Cloudflare Pages.

This is a static HTML/CSS/JS site, so no paid hosting is required.
